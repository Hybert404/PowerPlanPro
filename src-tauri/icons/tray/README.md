# Tray Icons

Put your prepared tray icons in this folder.

## Expected names (planned for next step)

- `plan-power-saver.ico`
- `plan-balanced.ico`
- `plan-high-performance.ico`
- `plan-unknown.ico`

Notes:
- Keep icons in `.ico` format for Windows tray compatibility.
- Prefer 16x16 and 32x32 sizes embedded in each `.ico`.
- Use concise, high-contrast glyphs for tray readability.
